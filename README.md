A Python program — standard library only, no network — that writes one sentence to /output/entry.txt: a pitch for the Apology Toaster, a ridiculous invention that fixes the tiny annoyance of burnt breakfast by browning the word "sorry" onto the next slice. The sentence is 157 characters, inside the competition's gate of 1 to 220 characters, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
